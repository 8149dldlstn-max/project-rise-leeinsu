# 배포 가이드 — 다른 곳에서 MVP 확인하기

> 이 문서는 코드/설정 준비까지만 다룹니다. **Render 계정 생성·GitHub 연결·시크릿 값 입력은 보안상 사용자 본인이 직접 해야 합니다** (계정 생성, 비밀번호/API 키 입력은 AI가 대신 할 수 없는 영역).

## 이미 준비된 것
- GitHub 저장소: https://github.com/8149dldlstn-max/project-rise-leeinsu (최신 코드 push 완료)
- `render.yaml` — Render가 저장소를 인식하면 백엔드(Web Service) + 프론트엔드(Static Site) 두 개를 한 번에 만들어주는 설계도
- `src/main.ts` — Render가 주입하는 `PORT` 환경변수를 우선 사용하도록 수정 완료
- `frontend-test/config.js` — 배포된 백엔드 주소를 한 줄만 바꾸면 프론트가 그 주소를 바라보도록 분리
- Supabase(Postgres + Storage)는 이미 실제 클라우드 서비스라 별도 배포 작업 불필요 — 지금 쓰는 프로젝트를 그대로 씀

## 1. 백엔드 배포 (Render)
1. https://render.com 접속 → **GitHub으로 로그인**(계정 생성은 본인이 진행)
2. 대시보드에서 **New → Blueprint** 선택 → `project-rise-leeinsu` 저장소 선택
   - Render가 `render.yaml`을 읽어 `art-collab-backend`(웹서비스)와 `art-collab-frontend`(정적사이트)를 자동으로 제안합니다
   - 만약 Blueprint가 안 뜨면 수동으로: **New → Web Service** → 저장소 선택 → Build Command `npm install && npm run build`, Start Command `node dist/main`
3. 배포 진행 전에 **환경변수(Environment)** 탭에서 아래 값을 채워야 합니다 (로컬 `.env`와 같은 값, `.env` 파일을 열어서 그대로 옮기면 됨):
   - `DATABASE_HOST`, `DATABASE_PORT`, `DATABASE_NAME`, `DATABASE_USERNAME`, `DATABASE_PASSWORD`
   - `JWT_SECRET`
   - `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`
   - (`NODE_ENV`, `DATABASE_SYNCHRONIZE`, `DATABASE_SSL`, `JWT_ACCESS_EXPIRATION_SECONDS`는 `render.yaml`에 이미 값이 박혀있어 안 건드려도 됨)
4. 배포가 끝나면 Render가 `https://art-collab-backend-xxxx.onrender.com` 같은 주소를 줍니다. 이 주소를 복사해두세요.
5. 확인: 그 주소 뒤에 `/api-docs`를 붙여서 접속(`https://art-collab-backend-xxxx.onrender.com/api-docs`) → Swagger가 뜨면 성공.

> 무료 플랜은 트래픽이 없으면 슬립 모드로 들어가서, 첫 요청 시 30초~1분 정도 깨어나는 데 걸릴 수 있습니다. MVP 시연용으로는 문제없는 수준.

## 2. 프론트엔드 배포 (Render 정적 사이트)
Blueprint로 같이 배포됐다면 이미 끝난 상태입니다. 수동으로 할 경우:
1. **New → Static Site** → 같은 저장소 선택
2. Publish Directory: `frontend-test`
3. Build Command는 비워두거나 `echo "no build"`

## 3. 프론트가 배포된 백엔드를 바라보게 연결
1. [frontend-test/config.js](../frontend-test/config.js) 파일을 열어서:
   ```js
   window.__API_BASE__ = '';
   ```
   를 1단계에서 받은 백엔드 주소로 바꿉니다:
   ```js
   window.__API_BASE__ = 'https://art-collab-backend-xxxx.onrender.com';
   ```
2. 변경 내용을 커밋 & push하면 Render 정적 사이트가 자동으로 재배포됩니다.

## 4. 완료 후 확인
- 프론트 주소(`https://art-collab-frontend-xxxx.onrender.com`)에 접속해서 로그인 → 게시물 작성 → 업로드까지 실제로 눌러보고 확인
- 다른 사람에게는 이 프론트 주소만 공유하면 됨 (백엔드 주소는 API용이라 직접 줄 필요 없음, `/api-docs`만 개발 확인용으로 공유 가능)

## 참고: 왜 계정 생성·시크릿 입력을 AI가 안 하는지
Render 로그인/계정 생성, `.env`의 비밀번호·API 키를 웹 폼에 입력하는 작업은 보안상 사용자 본인만 해야 하는 영역이라 여기까지만 자동화했습니다. 위 단계들은 전부 클릭 몇 번이면 끝나는 수준입니다.
