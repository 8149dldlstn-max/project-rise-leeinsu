# 7ill — 협업 커뮤니티 앱 스펙 v2.0 (7ill_기획문서.xlsx 반영)

> **스택:** NestJS + TypeORM + Supabase(Postgres + **Storage**) + Render + Swagger.
> **정체:** 팀원이 음악·영상·춤 등 작업물을 올리고, **특정 시·분·초에 태그/이모지/댓글**로 피드백하거나, 자유게시판·전체 채팅으로 소통하는 커뮤니티 앱.
> **결정(부풀림 방지):** 인증은 **이메일+비번(표준)** 으로 시작(QR·기기바인딩 나중). 버전관리·파형·A/B는 v2.
> **참고:** 화면 흐름·확정 근거는 `7ill_기획문서.xlsx` (개요/화면 흐름도/화면별 상세 명세/글쓰기 플로우 상세/미정리·확인 필요 항목) 참고.

## 엔티티

**User** — id(PK) · email(로그인 아이디) · password · nickname · **statusMessage(마이페이지 상태, CRUD)** · **profileImageUrl(프로필 사진, Supabase Storage URL, nullable)** · **role(enum: USER/ADMIN, 기본 USER — DB에서 수동 지정)** · createdAt

**Post** *(게시물 — 작업물공간 또는 자유게시판)* — id(PK) · authorId(FK) · **boardType(enum: WORK/FREE, 게시판 동시 선택 불가)** · tagId(FK→Tag, nullable) · title(50자 내외) · content(500자 이내) · createdAt
> 파일(이미지 최대 10장/음악 1개/영상 1개)은 `PostFile`에 정규화 저장. API 응답에는 기존과 동일하게 `imageUrls`(string[])·`musicUrl`·`videoUrl`로 조립해서 내려준다(계약 불변).

**PostFile** *(게시물 첨부파일 — Post 1:N)* — id(PK) · postId(FK→Post) · type(enum: IMAGE/MUSIC/VIDEO) · url(Supabase Storage 공개 URL) · createdAt
> 게시물 삭제 시 함께 삭제(DB FK CASCADE). 현재는 음악·영상도 이 테이블에 함께 저장(추후 필요 시 분리 검토).

**Tag** *(고정 태그)* — id(PK) · name(unique) · createdAt

**TagRequest** *(신규 태그 요청)* — id(PK) · requesterId(FK→User) · name · status(enum: PENDING/APPROVED/REJECTED) · createdAt
> 어드민(role=ADMIN)이 승인하면 `Tag`에 자동 반영. 대기 노출 배지·중복 요청 방지·거절 사유 같은 세부 로직은 **만들지 않음**(단순 승인/거절 목록이면 충분 — 필요 시 v2에서 보완).

**TimelineMark** *(시·분·초 마크 — 이 앱의 특색, 작업물공간(WORK) 게시물 전용)* — id(PK) · postId(FK) · authorId(FK) · **timestampSec(number, 몇 초 지점)** · kind(enum: TAG / EMOJI / COMMENT) · tag(string, 선택) · emoji(string, 선택) · content(text, 선택) · createdAt

**Comment** *(일반 댓글 — 자기참조 중첩, 작업물공간·자유게시판 공통)* — id(PK) · postId(FK) · authorId(FK) · parentId(FK→Comment, nullable) · content · createdAt

**ChatMessage** *(전체 공개 채팅 — 라운지 우측 상시 노출, 방 구분 없음)* — id(PK) · authorId(FK) · content · createdAt

**PasswordResetRequest** *(비밀번호 재설정 — 어드민이 임의 코드 발급)* — id(PK) · userId(FK) · code(nullable, 발급 시 채움) · status(enum: PENDING/ISSUED/USED) · createdAt

## 관계

*들여쓰기 안쪽 = 포함(1:N) · ↔ = 다대다(M:N, 중간테이블)*

```
User (회원, role로 일반/어드민 구분)
 ├─ Post (작업물공간 또는 자유게시판, boardType으로 구분)
 │   ├─ PostFile (이미지·음악·영상 첨부파일)          1:N
 │   ├─ TimelineMark (시·분·초 마크 — WORK 게시물만)   1:N
 │   └─ Comment (댓글)                              1:N  ·· parentId 자기참조(대댓글)
 ├─ TagRequest (신규 태그 요청 → 승인 시 Tag 반영)      1:N
 ├─ ChatMessage (전체 채팅)                          1:N
 └─ PasswordResetRequest (비밀번호 재설정 요청)         1:N

Post ↔ Tag : Post N:1 Tag (게시물 하나에 고정 태그 하나 선택, nullable)

M:N 없음 — 포함(1:N) + 자기참조
```

## API

- 인증: `POST /auth/register` · `POST /auth/login`
- 비밀번호 재설정: `POST /auth/password-reset/request` · `POST /auth/password-reset/confirm`(코드+새 비밀번호)
- 어드민: `GET /admin/password-reset-requests` · `PATCH /admin/password-reset-requests/:id/issue-code` · `GET /admin/tag-requests` · `PATCH /admin/tag-requests/:id/approve` · `PATCH /admin/tag-requests/:id/reject`
- 마이페이지: `GET /me` · `PATCH /me/status`(상태 메시지) · `PATCH /me/profile-image`(프로필 사진 URL) · `GET /me/posts`(내가 쓴 글 목록)
- 파일 업로드: `POST /files/upload`(multipart, 이미지·영상·음성만·50MB 이하) → Supabase Storage 공개 URL 반환. 프로필 사진·게시물 첨부 모두 이 URL을 사용
- 게시글: `POST /posts`(boardType·tagId·fileUrls) · `GET /posts?boardType=&tagId=` · `GET /posts/:id` · `PATCH /posts/:id` · `DELETE /posts/:id`(작성자 본인 또는 어드민만)
- 태그: `GET /tags`(고정 목록) · `POST /tag-requests`(신규 요청)
- 시분초 마크: `POST /posts/:id/marks`(timestampSec·kind·tag/emoji/content, WORK 게시물 한정) · `GET /posts/:id/marks` · `PATCH /posts/:id/marks/:markId`(작성자 본인 또는 어드민만) · `DELETE /posts/:id/marks/:markId`(작성자 본인 또는 어드민만)
- 댓글: `POST /posts/:id/comments`(parentId 선택) · `GET /posts/:id/comments` · `PATCH /posts/:id/comments/:commentId`(작성자 본인 또는 어드민만) · `DELETE /posts/:id/comments/:commentId`(작성자 본인 또는 어드민만, 대댓글도 함께 삭제)
- 채팅: `GET /chat/messages` · `POST /chat/messages` (1차는 REST 폴링, 프론트는 3초 간격 자동 갱신 — 실시간(WebSocket) 전환은 이후 검토)
- 팀원 목록: `GET /users`(로그인한 사용자면 누구나 — 전체 팀원의 닉네임·상태메시지 조회, 이메일 등 민감정보 제외)

## 핵심 규칙

- **파일:** 이미지 최대 10장(장당 10MB) · 음악 1개(30MB) · 영상 1개(150MB) → Supabase Storage에 업로드 후 URL만 저장. **Supabase 프로젝트의 실제 업로드 상한(Storage→Settings)을 배포 전 확인**할 것.
- **게시판은 작업물공간(WORK)/자유게시판(FREE) 중 하나만 선택** — 동시 게시 불가(1:1).
- **태그는 고정 목록에서 선택.** 신규 태그는 `TagRequest`로 요청 후 어드민 승인 시 `Tag`에 자동 반영(단순 승인/거절만, 세부 로직 없음).
- **시분초 피드백의 정체 = `timestampSec` 하나.** 파형 그림은 프론트, 백엔드는 위치·내용만 저장. **작업물공간(WORK) 게시물에서만 사용.**
- 자유게시판 상세는 작업물공간 상세와 **동일한 댓글·수정/삭제 규칙**을 적용.
- **게시물·댓글·시분초 마크의 수정/삭제는 작성자 본인 또는 role=ADMIN만** 가능(소유권 검증, 없으면 404 / 남의 것 403).
- **댓글 삭제 시 대댓글도 함께 삭제**(CASCADE) — 게시물 삭제 시 댓글·마크가 함께 삭제되는 것과 동일한 원칙.
- **팀원 목록(`GET /users`)은 닉네임·상태메시지·프로필사진만 노출**, 이메일·role 등은 제외(마이페이지 `/me`에서만 본인 정보로 확인).
- **비밀번호 재설정은 어드민이 발급한 임의 코드로 진행**(이메일 자동 발송 아님).
- 상태 메시지 = User 필드 CRUD.
- **채팅은 전체 공개 채팅방 1개**, 발신자는 로그인 닉네임으로 표시.

## In / Out

- **In:** 회원가입·로그인(이메일 아이디) · 비밀번호 재설정(어드민 코드 발급) · 마이페이지(상태메시지+프로필사진+내가 쓴 글) · 파일 업로드(Supabase Storage, 이미지·영상·음성·50MB) · 게시글 CRUD(작업물공간/자유게시판, 파일 업로드, 고정 태그) · 태그 추가 요청 + 어드민 승인/거절(단순) · 시분초 태그/이모지/댓글 CRUD(작업물공간 한정) · 일반 댓글 CRUD(대댓글) · 전체 공개 채팅(1차 REST, 프론트 3초 폴링) · 팀원 목록 조회(닉네임·상태메시지·프로필사진)
- **Out(v2):** 태그 승인 세부 로직(대기 노출 배지·중복 요청 방지·거절 사유) · 신고/모더레이션 · 알림 기능 · 버전관리(WorkVersion) · 파형 시각화 · A/B 플레이어 · QR/기기바인딩 인증 · 채팅 실시간화(WebSocket)
